# Web Sticky Scroll

[![CI](https://github.com/dongruixiao/web-sticky-scroll/actions/workflows/ci.yml/badge.svg)](https://github.com/dongruixiao/web-sticky-scroll/actions/workflows/ci.yml)

> **TopClip — 读长文，不掉线**
> 仓库名 `web-sticky-scroll` 是技术标识；面向用户的产品名是 TopClip。

阅读长文时，真正容易丢失的往往不是导航，而是**当前这一节在讲什么**。往下滚动几屏后，眼睛还在正文里，
上下文却已经断了。TopClip 用一枚始终显示当前章节的拟物胶囊，帮你保持内容记忆；目录和进度是顺带的辅助。

## 产品形态

TopClip 现在只有一种稳定形态：**可自由拖动的拟物章节胶囊**。

- 胶囊显示当前章节标题，不复制网页标题、不伪造页面结构。
- 胶囊可拖到视口内任何位置，位置按站点记忆，双击恢复默认位置。
- 胶囊左边缘固定，标题变长时只向右扩展；目录保持固定的章节版心宽度并与胶囊左对齐。
- 靠近屏幕底部时，目录自动向上展开；两者之间保留明确但克制的间距。
- 窗口缩放后会重新夹在可视区域内，不会留下一个点不到的控件。
- 胶囊采用拉丝金属外壳与深色内嵌目录屏：实体高光、机械缝线、状态灯和一致的字体层级。
- 目录不显示“文章目录”标题、百分比或额外滚动条，只保留章节路径和大纲。
- 整篇阅读进度环绕在左侧拟物徽标外圈：读得越多圆环越完整，读到文末正好闭合。

早期版本的全宽无痕吸顶、网页标题克隆、列宽对齐和轻提示模式已经移除。它们对页面结构要求过高，
容易在不同网站上产生错位或遮挡；TopClip 不再尝试改造网页，而是提供一个独立、克制、可控的阅读辅助层。

## 显示策略

| 策略 | 行为 |
| --- | --- |
| 智能 | 向下阅读时浮现；向上回看时让位；静止后降低存在感。推荐日常阅读。 |
| 常驻 | 始终显示胶囊，位置仍可自由拖动。 |

通过目录主动跳转时，智能模式会短暂保持胶囊可见，避免用户刚点完导航控件就消失。

## 功能

**内容提醒**

- 当前章节标题跟随滚动实时更新，只显示当前层级，不把整条路径堆在胶囊里。
- 标题发生切换时按真实几何位置判定，避免向下滚动提前切换、向上回滚仍显示下级标题。
- 文章顶部和文章末尾都有专门处理，不会为了“填满界面”提前展示尚未进入阅读位置的章节。

**导航**

- 悬停胶囊展开完整目录树，当前小节高亮，上级路径可点击回溯。
- 点击胶囊标题可钉住目录；再次点击、点击页面空白处或按 `Esc` 收起。
- `Alt+[` / `Alt+]` 跳到上一节 / 下一节。
- 页面自带目录可见时自动退让为当前小节指示器，避免两套目录互相打架；目录滚出视口后恢复完整功能。

**阅读进度**

- 左侧拟物徽标外圈显示整篇文章进度，而不是单个小节进度。
- 0% 从正文进入阅读区域开始，读到正文末尾时圆环完整闭合。
- 进度不再占用网页顶部，也不会在胶囊收起后留下一条孤立横线。

**站点与隐私**

- 支持当前站点一键停用；不提供复杂的域名规则维护。
- 设置使用 `chrome.storage.sync` 跨设备同步。
- 不发送页面内容、不接入遥测、不加载远程代码；所有识别和渲染都在本地完成。

## 何时出现

内容脚本会加载在所有 `http/https` 页面，但只有结构可信的长文 / 文档页才显示 UI。
判定基于页面形态而不是域名硬编码，主要参考：

| 信号 | 作用 |
| --- | --- |
| 正文段落量、有效标题数、小节长度 | 排除过短页面、列表页和空壳页面 |
| 链接文字占比、段落文字占比 | 排除导航页、搜索结果和卡片墙 |
| 标题占全页比例、标题层级 | 排除列表中的单张文章卡片 |
| 标题几何与可见性 | 标题重叠、零尺寸或多栏错位时宁可不显示 |
| 持续对话轮次 + 输入区结构 | 排除 ChatGPT、Gemini 等聊天 / 代理工作区 |
| 正文容器与侧栏过滤 | 避免把页脚、导航和评论区标题当作文章章节 |

原则是：**宁可漏掉一个边缘页面，也不在错误场景里展示。** 如果页面结构无法可靠理解，
TopClip 保持静默，不在页面上留下空胶囊或异常 DOM。

## 适用场景

| 场景 | 预期 |
| --- | --- |
| 技术文档、Wiki、README | 支持 |
| 学术论文 HTML 版、法律条文 | 支持 |
| Wikipedia、个人博客、Substack 类长文 | 结构可信时支持 |
| 有章节结构的中文长文 | 结构可信时支持 |
| 列表页、搜索结果、营销首页 | 保持静默 |
| AI 聊天 / 对话式工作区 | 保持静默 |
| 没有小节标题的长文 | 保持静默 |
| PDF 内置阅读器 | 不支持，Chrome PDF 阅读器不在网页 DOM 中 |

## 交互细节

- **拖动**：按住胶囊拖动，达到 4px 位移后才进入拖动状态，普通点击仍可打开目录。
- **位置恢复**：位置按 hostname 保存为相对视口坐标；不同窗口尺寸下仍会留在安全边界内。
- **双击复位**：双击胶囊清除当前站点的自定义位置，回到顶部默认锚点。
- **原站目录**：只在屏幕上真正可见时退让；原站目录消失后恢复悬停大纲。
- **浏览器查找**：按 `Ctrl/⌘+F` 时收起胶囊，避免遮挡查找条；按 `Esc` 或回到页面后恢复。
- **高层浮层**：站点对话框、搜索面板或其它扩展的更高层 UI 出现时让位，不强行覆盖。
- **异常熔断**：连续布局异常时销毁 UI、监听器、计时器和页面标记，本页会话不再重试；
  刷新页面会重新尝试，升级版本也不会被旧页面的熔断状态永久锁住。

## 设置

| 选项 | 默认 |
| --- | --- |
| 开启 / 关闭 TopClip | 开启 |
| 智能 / 常驻 | 常驻 |
| 当前站点停用 / 启用 | 跟随用户操作 |
| 恢复默认设置 | — |

显示策略只保留“智能”和“常驻”。旧版本保存的轻提示选择会自动迁移到“智能”，不会让用户丢失设置。
拖动位置按站点记忆；主题跟随系统，原站目录退让、文章大标题隐藏和大纲裁剪都使用固定规则，不再暴露为深层设置。

## 项目结构

```text
web-sticky-scroll/
├── manifest.json
├── src/
│   ├── content/
│   │   ├── index.ts          # 生命周期、显示策略、站点门控、消息响应
│   │   ├── extractor.ts      # 正文容器识别与标题树
│   │   ├── conversation.ts   # 对话 / 代理工作区识别
│   │   ├── page-toc.ts       # 原站目录探测
│   │   ├── path.ts           # 路径裁剪
│   │   ├── tracker.ts        # 滚动、活跃标题、整篇进度
│   │   ├── ui.ts             # Shadow DOM 胶囊、拖动与目录
│   │   └── style.css         # 拟物胶囊与内嵌仪表屏样式
│   ├── popup/                # 快捷开关
│   ├── options/              # 基础设置页
│   ├── background/           # service worker
│   └── shared/               # 设置、常量和版本约束
├── e2e/                      # 浏览器端到端与真实站点检查
├── demo/                     # 本地演示页
├── store/                    # 商店文案、隐私政策、截图素材
└── scripts/                  # 图标生成与打包
```

## 开发

```bash
npm install
npm run typecheck
npm test
npm run build
npm run e2e
npm run field-check
```

加载开发版：`chrome://extensions` → 开启开发者模式 →「加载已解压的扩展程序」→ 选择 `dist/`。

`npm run e2e` 需要支持 `--load-extension` 的 Chromium / Chrome for Testing。也可以通过
`WSS_CHROME_PATH=/path/to/chrome npm run e2e` 指定浏览器；Chrome 137+ 正式版不能再用命令行加载未打包扩展。

完整发布前验证：

```bash
npm run typecheck
npx vitest run
npm run build
WSS_CHROME_PATH="/path/to/chrome" npm run e2e
WSS_CHROME_PATH="/path/to/chrome" npm run field-check
npm run package
```

## 发布到 Chrome 应用商店

商店文案、权限说明、截图和隐私政策在 [`store/`](store/) 目录。`npm run package` 会生成
`release/web-sticky-scroll-<version>.zip`，zip 根目录就是 `manifest.json`，可直接上传开发者信息中心。

发布前请确认：

- `manifest.json` 与 `package.json` 版本号一致。
- 单测、端到端和真实站点检查通过。
- `storage` 权限与实际行为一致，内容脚本只匹配 `http/https`。
- 更新商店截图与隐私政策后重新打包。

版本历史见 [Releases](https://github.com/dongruixiao/web-sticky-scroll/releases)。

## 当前取舍

- 不向页面插入占位元素，也不修改网页原始标题或正文布局。
- 不内置域名白名单来“假装适配”；激活范围由通用页面结构判断。
- AI 小节摘要属于独立服务能力，当前版本不包含。
- PDF 阅读器、浏览器内置页和扩展商店页面不在 DOM 内容脚本能力范围内。
