## 详细说明

TopClip —— 读长文，不掉线。

阅读长文时，真正容易丢失的不是目录位置，而是当前这一节在讲什么。往下滚动几屏后，眼睛还在字里，
上下文却已经断了。TopClip 用一枚带金属质感的拟物胶囊显示当前章节，让你随时知道自己在读什么。

它不改造网页，也不伪造站点的标题：

- 可自由拖动的拟物胶囊，位置按站点记忆，双击恢复默认
- 拉丝金属外壳、深色内嵌目录屏与状态灯；目录不占额外滚动条空间
- 悬停查看按标题树组织的完整目录，点击平滑跳转到对应章节
- 页面顶部 1px 紫色细线显示整篇文章进度，不依赖网页配色
- 智能 / 常驻两种显示策略：向下阅读时浮现，或始终显示
- 胶囊与目录左边缘对齐、宽度固定，标题变化不会抖动；拖到下方时目录向上展开
- 原站已有目录时自动退让，避免两套目录互相干扰
- 页面查找、站点对话框和其它高层浮层出现时主动让位
- 智能识别长文与文档；列表页、搜索页、营销页和 AI 聊天页保持静默
- 不按域名硬编码场景；结构不可靠时宁可不显示
- 快捷键 Alt+[ / Alt+] 跳到上一节 / 下一节
- 支持当前站点一键禁用，以及黑名单 / 白名单

适用场景：技术文档、Wiki、README、学术论文 HTML 版、法律条文、Wikipedia、
个人博客和 Substack 类长文，以及其它带章节结构的网页。

PDF 内置阅读器不在网页 DOM 中，无法支持；没有小节标题或结构不可信的长文会保持静默。

## 隐私

不联网、不收集数据、不含统计埋点。页面标题和阅读进度只在你的浏览器本地处理，
仅使用 storage 权限保存设置，并通过 Chrome 账号同步你的偏好。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存 / 同步显示策略、胶囊位置、主题和站点规则；不读取浏览历史，不保存正文 |
| 内容脚本（http / https） | 在网页中识别正文与标题结构；只有判定为合适的长文 / 文档页才显示胶囊 |

## 单一用途说明

在网页阅读时显示当前章节标题，帮助读者保持对当前内容的记忆，并提供可选的目录导航与整篇阅读进度。

## 上传与发布流程

1. 用要发布的 Google 账号登录 https://chrome.google.com/webstore/devconsole
2. 首次填写开发者名称与联系邮箱，并支付一次性 5 美元注册费
3. 「新建项目」→ 上传 `npm run package` 生成的 zip
4. 填写商店信息、截图、权限用途和隐私声明
5. 选择可见性；想先小范围试用可选择「不公开」
6. 提交审核；按审核反馈修改后重新上传

## 更新版本

1. 同步修改 `manifest.json` 与 `package.json` 的 version
2. 执行 `npm run package`
3. 在开发者信息中心上传新 zip 并提交审核
