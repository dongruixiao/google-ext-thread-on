# Chrome 应用商店上架材料

直接复制粘贴到开发者信息中心。字段长度都按商店限制校过。

## 基本信息

| 字段 | 内容 |
| --- | --- |
| 名称 | 顶阅 — 网页章节吸顶导航 |
| 简短说明（132 字符内） | 读长文不迷路：当前章节标题原样吸在页面顶部（Sticky Headings），悬停展开层级目录，原站已有目录时自动让位。技术文档、学术论文、法律条文、万字长文都适用。 |
| 类别 | 生产力工具（Productivity） |
| 语言 | 中文（简体），可另加 English |
| 官网 | 可选：填项目仓库或介绍页 |

## 详细说明

读长文、看文档时最怕滚着滚着忘了自己在哪一节。顶阅把当前小节标题
「吸」在页面顶部——不是悬浮控件，而是把网页里那个标题原样搬上去：字体、字号、
颜色、行高全部与页面一致，看起来就像页面自带的第二条顶端栏。

主要功能

- 吸顶章节标题：标题滑到条后面才接管，回滚时上级标题一露头就交还，不会有漂浮感
- 悬停展开文章目录：按标题树嵌套显示，带层级引导线，当前小节高亮
- 点击钉住目录：方便通读全文结构；点空白处或按 Esc 收起
- 点击任意层级平滑跳转，落点正好停在标题下方
- 整篇阅读进度：条底部通栏细线
- 智能激活：只在长文 / 文档页出现，列表页、搜索结果、营销首页保持静默
- 原站目录适配：页面自带目录在屏幕上时自动让位，只显示当前小节
- 站点规则：支持黑 / 白名单，可在当前站点一键禁用或强制启用
- 界面随页面配色：深色站点自动深色，也可手动指定浅色 / 深色
- 键盘：Alt+Shift+S 切换当前站点，Alt+Shift+W 切换全局开关

隐私

不联网、不收集任何数据、不含任何统计埋点。所有处理都在你的浏览器本地完成，
仅使用 storage 权限保存你的设置。

## 权限说明（审核会问到，可直接粘贴）

| 权限 | 用途说明 |
| --- | --- |
| `storage` | 保存 / 同步你的偏好设置（显示策略、外观形态、站点规则），不涉及任何浏览内容 |
| 内容脚本（http / https） | 需要在任意网页上识别正文结构；只有判定为长文 / 文档页时才显示界面，其他页面保持静默 |

## 单一用途说明

在网页阅读场景下，把当前章节标题吸顶显示并提供目录导航。

## 数据使用声明（开发者信息中心 → 隐私标签页）

- 是否收集用户数据：不收集
- 是否使用远程代码：否（所有代码随包分发，无 CDN、无 eval、无动态加载脚本）
- 是否使用分析 / 统计：否

## 上传与发布流程

1. 用要发布的 Google 账号登录 https://chrome.google.com/webstore/devconsole
2. 首次需填写开发者名称与联系邮箱（需验证），支付一次性 5 美元注册费；账号需开启两步验证
3. 「新建项目」→ 上传 npm run package 生成的 zip
4. 填写「商店信息」：名称、简短说明、详细说明、类别、语言、截图
5. 填写「隐私」：按上面的声明逐项选择；权限用途粘贴上表内容
6. 选择可见性：公开 / 不公开（仅链接）/ 私密。想先给自己人试就选「不公开」
7. 提交审核。首次通常几小时到几天；被拒会给出具体条目，按其说明修改后重新提交

## 更新版本

1. 同时修改 manifest.json 与 package.json 里的 version（两处必须一致），例如 0.3.1
2. npm run package
3. 开发者信息中心 → 你的项目 → 软件包 → 上传新 zip → 提交审核

未打包安装的用户（开发者模式）只需在 chrome://extensions 点一下刷新。
