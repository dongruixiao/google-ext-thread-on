# 隐私政策 — TopClip

最后更新：2026-10-23

## 我们收集什么

**什么都不收集。**

- 扩展不发起任何网络请求，不包含统计、埋点、广告或第三方 SDK
- 不读取、不上传、不存储你的浏览记录、页面内容、输入内容或任何个人身份信息
- 页面分析（识别正文容器与标题层级）全部在你的浏览器本地完成，结果不离开本机

## 扩展会用到什么

| 能力 | 用途 |
| --- | --- |
| 在网页中注入界面（content script） | 在长文 / 文档页面顶部显示当前章节标题与目录；判定不通过时不显示任何界面 |
| `storage` 权限 | 保存你的偏好设置（显示策略、胶囊位置、站点停用列表），并随 Chrome 账号同步 |

## 你的控制权

- 点击工具栏图标后，可在弹窗中随时关闭总开关
- 可在扩展弹窗中对当前站点一键停用或重新启用
- 卸载扩展会一并删除本地与同步存储中的设置
